# Writz Hub Landing

Crée une landing page responsive de présentation pour un script nommé « Writz Hub ». Style dark premium hacker/tech : fond #0a0a0a/#111, accents blanc et gris clair, sans-serif nette, grands espaces, glassmorphism subtil avec bordures blanches peu opaques. Sections : hero avec logo/nom Writz Hub et animation texte élégante (typewriter/fade cascade ou glitch subtil), CTA « Télécharger » avec hover glow/scale/ripple et bordure lumineuse animée ; bandeau marquee infini d’executors compatibles (Xeno, Solara, Delta, etc.) ; grille fonctionnalités/scripts avec cartes glass et animations fade-up stagger au scroll + icônes hover ; statistiques avec compteurs qui s’animent à l’entrée dans le viewport ; showcase avec mockup visuel du script, parallaxe légère au scroll et tilt 3D au survol ; footer Discord, GitHub, etc. Intègre un fond discret de particules ou grille animée qui réagit légèrement à la souris, un curseur personnalisé avec point et traînée sur desktop, reveal progressif des titres mot par mot, Intersection Observer pour les reveals, et transitions cubic-bezier fluides. Pas de dépendances lourdes. Le résultat doit être soigné, cohérent et mobile-friendly.
