# Writz Hub Landing

Crée une landing page responsive de présentation pour un script nommé « Writz Hub ». 
Style dark premium hacker/tech : fond #0a0a0a/#111, accents blanc et gris clair, sans-serif nette, grands espaces, glassmorphism subtil avec bordures blanches peu opaques.

## Sections

- Hero avec logo/nom Writz Hub et animation texte élégante (typewriter/fade cascade ou glitch subtil)
- CTA « Télécharger » avec hover glow/scale/ripple et bordure lumineuse animée
- Bandeau marquee infini d’executors compatibles (Xeno, Solara, Delta, etc.)
- Grille fonctionnalités/scripts avec cartes glass et animations fade-up stagger au scroll + icônes hover
- Statistiques avec compteurs qui s’animent à l’entrée dans le viewport
- Showcase avec mockup visuel du script, parallaxe légère au scroll et tilt 3D au survol
- Footer Discord, GitHub, etc.

## Features

- Fond discret de particules ou grille animée qui réagit légèrement à la souris
- Curseur personnalisé avec point et traînée sur desktop
- Reveal progressif des titres mot par mot
- Intersection Observer pour les reveals
- Transitions cubic-bezier fluides
- Pas de dépendances lourdes
- Mobile-friendly

## Development

Prefer working locally? You need Node.js and npm.

```sh
npm i
npm run dev
```
