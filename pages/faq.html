Questions fréquentes

Trouvez des réponses aux questions les plus courantes sur Writz Hub.

Writz Hub est un script puissant conçu pour automatiser et optimiser vos tâches. Il prend en charge plusieurs executors populaires et offre une interface intuitive pour gérer vos automatisations.

Writz Hub se distingue par son interface moderne, ses performances optimisées, sa compatibilité multi-executors et son système de plugins modulaire. Nous offrons également un support réactif et une documentation complète.

Oui, Writz Hub est gratuit pour un usage personnel. Nous proposons également des plans premium pour les entreprises avec des fonctionnalités avancées comme le support prioritaire, l'accès aux versions bêta et bien plus.

Vous pouvez installer Writz Hub de plusieurs manières :

  1. Télécharger le script depuis notre page de téléchargement
  2. Installer via npm: npm install writz-hub
  3. Cloner le dépôt GitHub: git clone https://github.com/Travail-code/wrtiz-hub-landing.git

Writz Hub nécessite :

  • Un executor compatible (Xeno, Solara, Delta, etc.)
  • Node.js v14 ou supérieur (pour l'installation via npm)
  • 2 Go de RAM minimum (4 Go recommandé)
  • 50 Mo d'espace disque libre

Actuellement, Writz Hub est principalement conçu pour les systèmes desktop (Windows, macOS, Linux). Une version mobile est en développement et sera disponible prochainement.

Writz Hub est compatible avec les executors suivants :

  • Xeno
  • Solara
  • Delta
  • Eclipse
  • Krnl
  • JJSploit
  • Fluxus
  • Oxygen

Nous travaillons constamment pour ajouter la compatibilité avec d'autres executors.

Si vous rencontrez des problèmes d'installation :

  1. Vérifiez que Node.js est installé et à jour
  2. Assurez-vous que vous avez les permissions nécessaires
  3. Essayez de désactiver temporairement votre antivirus
  4. Consultez les logs pour identifier le problème
  5. Contactez notre support technique

Si Writz Hub ne détecte pas votre executor :

  1. Vérifiez que votre executor est dans la liste des executors supportés
  2. Assurez-vous que votre executor est à jour
  3. Vérifiez que le chemin de votre executor est correct dans la configuration
  4. Redémarrez Writz Hub
  5. Si le problème persiste, contactez notre support

Pour nous aider à résoudre votre problème, veuillez inclure les informations suivantes dans votre rapport de bug :

  • Version de Writz Hub
  • Executor utilisé
  • Système d'exploitation
  • Description détaillée du problème
  • Étapes pour reproduire le bug
  • Logs d'erreur (si disponibles)

Vous pouvez ouvrir un rapport de bug sur notre GitHub ou via notre formulaire de contact.

Pour mettre à jour Writz Hub :

  1. Si vous avez installé via npm : npm update writz-hub
  2. Si vous avez téléchargé le script manuellement : téléchargez la dernière version depuis notre page de téléchargement et remplacez les anciens fichiers
  3. Vérifiez la version installée avec la commande writz-hub --version
