Bienvenue sur Writz Hub

Writz Hub est un hub de scripts Roblox conçu pour fonctionner avec les principaux executors. Nos scripts vous permettent d'avoir un avantage dans vos jeux préférés avec des fonctionnalités comme le Fly, l'Auto Farm, l'AimBot, l'ESP et bien plus.

Installation

Suivez ces étapes simples pour installer Writz Hub sur votre executor préféré.

Méthode 1: Téléchargement direct (Recommandé)

  1. Téléchargez le fichier writz-hub.lua depuis notre page de téléchargement
  2. Ouvrez votre executor (Xeno, Solara, Delta, etc.)
  3. Chargez le script dans votre executor
  4. Exécutez le script avec la commande loadstring(game:HttpGet("PASTE_LINK_HERE"))()

Méthode 2: Via GitHub

  1. Allez sur notre dépôt GitHub: github.com/Travail-code/wrtiz-hub-landing
  2. Copiez le contenu du fichier main.lua
  3. Collez-le dans votre executor et exécutez

Méthode 3: Commande directe

Copiez et collez cette commande directement dans votre executor:

Executor 
loadstring(game:HttpGet("https://raw.githubusercontent.com/Travail-code/wrtiz-hub-landing/main/script.lua"))()

Comment choisir son executor ?

Voici quelques conseils pour choisir le meilleur executor selon vos besoins :

  • Pour les débutants : Xeno ou Eclipse (gratuits et faciles à utiliser)
  • Pour les joueurs sérieux : Solara ou Delta (payants mais plus puissants)
  • Pour les tests : JJSploit ou Krnl (gratuits mais moins stables)

Problèmes de compatibilité ?

Si un script ne fonctionne pas avec votre executor :

  1. Vérifiez que votre executor est à jour
  2. Essayez un autre executor de la liste ci-dessus
  3. Contactez notre support sur Discord

Dépannage

Solutions aux problèmes courants avec Writz Hub et les executors.

Le script ne s'exécute pas

Problèmes possibles :
  • Votre executor n'est pas compatible. Essayez Xeno, Solara ou Delta.
  • Le script n'est pas correctement chargé. Vérifiez la commande loadstring.
  • Votre executor est obsolète. Mettez-le à jour.
  • Roblox a mis à jour son anti-cheat. Attendez une mise à jour de Writz Hub.

Je me fais kick/bannir

Conseils pour éviter les bans :
  • N'utilisez pas plusieurs scripts en même temps
  • Désactivez les scripts quand vous ne les utilisez pas
  • Évitez d'utiliser des scripts dans les jeux avec anti-cheat avancé
  • Utilisez un compte alternatif pour tester les scripts

Le script plante mon jeu

Solutions :
  1. Rechargez le jeu (F5) et réessayez
  2. Désactivez tous les autres scripts
  3. Essayez avec un autre executor
  4. Vérifiez que vous avez copié correctement le script
