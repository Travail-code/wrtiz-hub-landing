À propos de Writz Hub

Writz Hub est un script puissant conçu pour automatiser et optimiser vos tâches. Il prend en charge plusieurs executors populaires et offre une interface intuitive pour gérer vos automatisations.

Avec Writz Hub, vous pouvez:

  • Automatiser vos tâches répétitives
  • Gérer plusieurs comptes simultanément
  • Optimiser vos workflows
  • Suivre vos performances en temps réel

Installation

L'installation de Writz Hub est simple et rapide. Suivez ces étapes:

Méthode 1: Téléchargement direct

  1. Téléchargez le script depuis la page de téléchargement
  2. Extrayez le fichier ZIP dans un dossier de votre choix
  3. Ouvrez le fichier writz-hub.js avec votre éditeur préféré

Méthode 2: Via npm

Terminal 
npm install writz-hub

Méthode 3: Via GitHub

Terminal 
git clone https://github.com/Travail-code/wrtiz-hub-landing.git
cd wrtiz-hub-landing

Configuration

Configurez Writz Hub selon vos besoins.

Fichier de configuration

Créez un fichier config.json à la racine de votre projet:

config.json 
{
  "executors": ["xeno", "solara", "delta"],
  "autoExecute": true,
  "optimize": true,
  "logLevel": "info",
  "maxConcurrentTasks": 5
}

Options de configuration

Option Type Description Valeur par défaut
executors Array Liste des executors à utiliser []
autoExecute Boolean Exécuter automatiquement les tâches false
optimize Boolean Optimiser les performances true
logLevel String Niveau de journalisation "info"
maxConcurrentTasks Number Nombre maximum de tâches simultanées 5

API Référence

Documentation complète de l'API Writz Hub.

Classes

WritzHub

Classe principale pour gérer Writz Hub.

Méthodes
initialize(config)

Initialise Writz Hub avec la configuration spécifiée.

JavaScript 
const hub = new WritzHub();
await hub.initialize({ autoExecute: true });
runScript(scriptName, params)

Exécute un script spécifique avec les paramètres donnés.

JavaScript 
await hub.runScript('auto-task', { repeat: 5 });
stopAll()

Arrête toutes les tâches en cours.

JavaScript 
await hub.stopAll();

Événements

Gestion des événements

Écoutez les événements de Writz Hub.

JavaScript 
hub.on('script:start', (scriptName) => {
  console.log(`Script ${scriptName} started`);
});

hub.on('script:complete', (scriptName, result) => {
  console.log(`Script ${scriptName} completed`, result);
});

hub.on('error', (error) => {
  console.error('Error:', error);
});

Exemples

Exemples pratiques pour vous aider à démarrer avec Writz Hub.

Exemple 1: Automatisation basique

example1.js 
const { WritzHub } = require('writz-hub');

const hub = new WritzHub();

async function main() {
  await hub.initialize({
    autoExecute: true,
    executors: ['xeno', 'solara']
  });

  // Run a simple script
  await hub.runScript('welcome');

  // Stop after 10 seconds
  setTimeout(async () => {
    await hub.stopAll();
  }, 10000);
}

main();

Exemple 2: Gestion des erreurs

example2.js 
const { WritzHub } = require('writz-hub');

const hub = new WritzHub();

// Listen for errors
hub.on('error', (error) => {
  console.error('An error occurred:', error);
});

// Listen for script completion
hub.on('script:complete', (scriptName, result) => {
  console.log(`${scriptName} completed successfully`, result);
});

async function runWithRetry(scriptName, maxRetries = 3) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      await hub.runScript(scriptName);
      return;
    } catch (error) {
      console.warn(`Attempt ${attempt} failed, retrying...`);
      if (attempt === maxRetries) throw error;
    }
  }
}

Dépannage

Solutions aux problèmes courants.

Problèmes d'installation

Le script ne s'installe pas

Assurez-vous que Node.js est installé et que vous avez les permissions nécessaires.

Terminal 
node -v
npm -v

Problèmes d'exécution

Le script ne s'exécute pas

Vérifiez que votre executor est compatible et que la configuration est correcte.

  • Vérifiez que l'executor est dans la liste des executors compatibles
  • Assurez-vous que le script existe dans le dossier scripts/
  • Vérifiez les logs pour plus d'informations

Problèmes de performance

Le script est lent

Essayez ces solutions pour améliorer les performances:

  1. Désactivez l'option debug dans la configuration
  2. Réduisez le nombre de tâches simultanées (maxConcurrentTasks)
  3. Utilisez un executor plus performant
  4. Fermez les autres applications gourmandes en ressources

Problèmes de sécurité

Erreurs de permission

Assurez-vous que Writz Hub a les permissions nécessaires:

Terminal 
# On Linux/Mac
chmod +x writz-hub.js

# On Windows (run as administrator)
