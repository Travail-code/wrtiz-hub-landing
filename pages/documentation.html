Installation

Follow these steps to install WritzHub:

Method 1: Direct Download

  1. Download script from Download page
  2. Open your executor (Xeno, Solara, Delta, etc.)
  3. Load the script in your executor
  4. Execute the script

Method 2: Direct Command

Copy and paste this command in your executor:

loadstring(game:HttpGet("https://raw.githubusercontent.com/Travail-code/wrtiz-hub-landing/main/script.lua"))()

Script Commands

Control WritzHub scripts with these commands:

Fly

WritzHub.ToggleFly(true)
WritzHub.ToggleFly(false)

Auto Farm

WritzHub.ToggleAutoFarm(true)
WritzHub.ToggleAutoFarm(false)

AimBot

WritzHub.ToggleAimBot(true)
WritzHub.ToggleAimBot(false)

ESP

WritzHub.ToggleESP(true)
WritzHub.ToggleESP(false)
